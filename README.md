# osama-raddad.github.io

This is the personal site of Osama Raddad, an Android Team Lead in Gothenburg: a single static page about his work on Android Automotive, his open-source Kotlin libraries (FireCrasher, Warehouse) and the Kotlin Multiplatform libraries he built at Vynatix (Holdfast, Hallmark), with his experience, writing and contact links. It is plain HTML and CSS with one small vanilla JavaScript file for progressive enhancement; there is no framework, build step, analytics or third-party request, and the fonts (Geist, Fraunces, JetBrains Mono) are self-hosted under `assets/fonts/` with their OFL licences in `assets/fonts/licences/`.

The design follows vynatix.com and the Vynatix Design System, in its Monochrome scheme (light and dark). The CSS comes in three layers, linked in this order: `assets/tokens.css` and `assets/colors_and_type.css` are the system's files, copied verbatim from the vynatix-site repository (refresh them by copying them over again; only the Monochrome faces are shipped, so the other `@font-face` rules in `tokens.css` are never fetched), and `assets/site.css` is this page's own layer, written with role tokens only (`var(--md-sys-color-primary)`, `var(--text-muted)`, `var(--space-6)`): no raw hex and no `[data-theme]` selectors, so every rule holds in both themes. As on vynatix.com, the header is a floating Liquid Glass capsule (its two lens filters are in the page's `.svg-defs` block, the maps in `assets/glass-lens-*.svg`), buttons are capsules, the contact band and the footer are inverse bands, and the background is silk: a still silk in CSS (`assets/silk-*.png`) and, where motion is allowed, folds drawn live in WebGL by `assets/site.js`. The footer's "Pause background motion" button is what makes that motion meet WCAG 2.2.2, so never ship one without the other. Without JavaScript, under reduced motion, after a pause or without WebGL the page shows the same still silk. `assets/site.js` loads in the `<head>` so the theme is set before the first paint; it holds the theme toggle (`localStorage` `theme`), the mobile menu, the silk and its pause button (`localStorage` `motion`), the copy buttons, the listings' tab stops and the header's marker for the section being read. `404.html` repeats the header and footer with absolute links, so a change to either is made in both files. To preview it locally, run `python3 -m http.server 8000` in the repository root and open http://localhost:8000/. The site deploys from the `main` branch with GitHub Pages.

When the content changes, bump the date in all four places: the “Last updated” note in the About section, `dateModified` in the JSON-LD, `article:modified_time` in the head, and `lastmod` in `sitemap.xml`. The FAQ restates facts from the project sections (install lines, release status, supported platforms), so update it together with them.
